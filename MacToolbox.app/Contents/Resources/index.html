📖 如何取得 Google Cloud OAuth 憑證？(3 步驟快速教學)
  1. 前往 Google Cloud Console 建立專案，在「API 與服務」>「資料庫」搜尋並啟用 Photos Library API。
  2. 在「OAuth 同意畫面」將使用者類型設定為「外部」，並在「測試使用者」加入您自己的 Gmail 地址。
  3. 在「憑證」建立「OAuth 用戶端 ID」，應用程式類型選「網頁應用程式」，並在「已授權的重新導向 URI」填入：
    http://127.0.0.1:18765/api/gphotos/oauth-callback
